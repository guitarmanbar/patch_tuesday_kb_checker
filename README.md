# patch_tuesday_kb_checker
Утилита для построения хронологии обновлений (CU) каждого продукта Microsoft

Перед запуском установите зависимости:
pip install requests pandas openpyxl

Для запуска выполните:
python patch_tuesday_updater.py

После завершения получите:
patch_tuesday_2024_2026.xlsx — итоговая таблица
patch_tuesday_raw.csv — сырые данные
